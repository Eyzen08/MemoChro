# MemoChro

A private photographic chronicle for ordinary days, people, places and longer stories. The public welcome page offers a clearly fictional, read-only sample archive. Sample data lives in source and never enters a user archive or Supabase.

This revision improves reading, writing and photo selection while preserving authentication, private originals, server validation and relationships. No autosave, drafts, database changes or new services. First visits use light mode; saved preferences win. Deploy to the existing protected preview only. Public hosting and SMTP stay unchanged.
